# LedgerLeaf 1.0 User Guide

## Add an expense

Use the centered **+** action. Enter the amount, category, payment method, date/time and mandatory notes. Favorite and recurring options are explicit toggles. Recurring entries remain editable drafts and never silently create a final expense.

## Find past spending

History supports Day, Week, Month and Year grouping. Search can use notes or structured filters such as category, payment method, date, amount, favorite and recurring status.

## Delete, restore and archive

Normal deletion requires double confirmation and moves an expense to Recycle Bin. Deleted records can be restored during the retention window. Archive is a separate historical state and archived records can also be restored.

## Reports and PDF

Reports are generated from local data on demand. Choose the period, preview totals/breakdowns, and save a PDF through Android's system file picker. PDF transaction and note detail can be configured in Settings.

## Backup and restore

Open Settings → Backup & Restore. Export a LedgerLeaf backup to a location you choose. Restore validates the file and relationships before replacing financial data transactionally. Keep backups in a location you control.

## Privacy

LedgerLeaf has no account, ads, analytics or tracking and does not require cloud connectivity.
