# Changelog

## 1.0.0 — 2026-08-10

- Completed the offline expense journal and notebook/ledger UI.
- Added expense creation, details, editing, backdating and mandatory notes.
- Added immutable system categories plus custom category foundations and payment methods.
- Added Favorites, Frequently Used and editable recurring-expense workflows.
- Added Day/Week/Month/Year history and offline search/filtering.
- Added Monthly Closing, six-month Recycle Bin and 18-month Archive.
- Added deterministic on-demand reports and offline PDF export.
- Added Settings, themes, budget/income preferences and PDF preferences.
- Added versioned user-controlled backup/restore with validation and transactional database replacement.
- Added accessibility, IME/inset and database performance hardening.
- Corrected the legacy Room 2→3 migration so the payment-method foreign key is created non-destructively and join relationships are preserved.
- Added JVM and Android integration/regression test coverage for critical financial and data-loss paths.
- Added release signing configuration via environment variables and release resource/code shrinking.
